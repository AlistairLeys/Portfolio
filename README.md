## 📁 Portfolio Projects

### 1. **Data Analysis: Customer Segmentation Analysis**
- **Location**: [`data-analysis/customer-segmentation/`](data-analysis/customer-segmentation/)

- **Tools**: Python, Pandas, Matplotlib, Seaborn
- **Description**: Comprehensive analysis of customer data to identify patterns and segments using clustering techniques and visualizations.

### 2. **Data Science: Sales Forecasting Model**
- **Location**: [`data-science/sales-forecasting/`](data-science/sales-forecasting/)
- **Skills**: Machine Learning, Time Series Analysis, Model Evaluation
- **Tools**: Python, Scikit-learn, XGBoost, Feature Engineering
- **Description**: Predictive model to forecast sales trends with feature engineering and hyperparameter tuning.

### 3. **AI Engineering: Sentiment Analysis Neural Network**
- **Location**: [`ai-engineering/sentiment-analysis/`](ai-engineering/sentiment-analysis/)
- **Skills**: Deep Learning, Natural Language Processing, Model Deployment
- **Tools**: Python, TensorFlow/PyTorch, Transformers, Neural Networks
- **Description**: Deep learning model for sentiment analysis with text preprocessing and neural network architecture.

## 🚀 Getting Started

### Prerequisites
```bash
# Python 3.8 or higher
python --version
```

### Installation
```bash
# Clone the repository
git clone https://github.com/AlistairLeys/Portfolio.git
cd Portfolio

# Install dependencies
pip install -r requirements.txt
```

### Running Projects
Each project directory contains its own README with specific instructions:
- Navigate to the project folder
- Follow the setup instructions in the project's README.md
- Run the Jupyter notebooks or Python scripts
