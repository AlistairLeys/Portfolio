# Customer Segmentation Analysis

## 📊 Project Overview

This project demonstrates comprehensive exploratory data analysis (EDA) and customer segmentation using clustering techniques. The analysis identifies distinct customer groups based on purchasing behavior, demographics, and engagement patterns.

## 🎯 Objectives

- Perform exploratory data analysis on customer data
- Identify patterns and correlations in customer behavior
- Apply clustering algorithms to segment customers
- Visualize customer segments and their characteristics
- Provide actionable insights for business strategies

## 📁 Dataset

The analysis uses a synthetic customer dataset with the following features:
- **CustomerID**: Unique identifier
- **Age**: Customer age
- **Income**: Annual income
- **SpendingScore**: Score (1-100) based on spending behavior
- **MembershipYears**: Years as a customer
- **PurchaseFrequency**: Average purchases per month

## 🔧 Technologies Used

- **Python 3.8+**
- **Pandas**: Data manipulation and analysis
- **NumPy**: Numerical computations
- **Matplotlib & Seaborn**: Data visualization
- **Scikit-learn**: K-means clustering and preprocessing

## 📈 Key Findings

The analysis reveals several customer segments:

1. **High-Value Customers**: High income, high spending score
2. **Budget-Conscious**: Lower income but consistent purchasing
3. **Occasional Shoppers**: Low purchase frequency
4. **Premium Segment**: High income, premium product preference
